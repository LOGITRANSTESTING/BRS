# BRS

ILISCyber BRS (Business Requirement Specification) workspace. Builds one BRS Word document per function from a Dr.Explain user manual, using the skill `.github/skills/iliscyber-brs` and the tools in `tools/` (`brs_plan.py`, `brs_img.py`, `brs_docx.py`, plus the house toolkit `ilis.py`).

Setup: `pip install -r requirements.txt`
