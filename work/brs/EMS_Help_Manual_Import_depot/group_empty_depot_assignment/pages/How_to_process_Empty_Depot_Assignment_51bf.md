## Pre defined conditions

@11 Selected PR container should not be in Prepared, Cancelled or Freeze status.

## Steps
**Step 1:** Enter the required query parameters in the search fields and click on {img:img/How_to_process_Empty_Depot_Assignment_51bf_01.png}.
**Step 2:** Upon clicking {img:img/How_to_process_Empty_Depot_Assignment_51bf_02.png}, BL records matching the entered criteria will be returned in the data grid.
**Step 3:** Select the desirable record(s) by either clicking on {img:img/How_to_process_Empty_Depot_Assignment_51bf_03.png} select all checkbox or {img:img/How_to_process_Empty_Depot_Assignment_51bf_04.png} individual selection individual selection checkbox of the respective BL.
**Step 4:** Click on the {img:img/How_to_process_Empty_Depot_Assignment_51bf_05.png} icon (Voyage level) and then select **Empty Depot Assignment** function from the menu. This will open the **Empty Depot Assignment** screen.
![](img/How_to_process_Empty_Depot_Assignment_51bf_06.png)

If process is successful, a success message is shown as given below and the records will be updated on the basis of Empty Pickup and Return setup.
>> ![](img/How_to_process_Empty_Depot_Assignment_51bf_07.png)
